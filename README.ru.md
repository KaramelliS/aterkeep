## Возможности

- **Автоматическое подтверждение очереди** — когда подходит ваша очередь, Aternos открывает окно примерно на 30 секунд; без ответа вы возвращаетесь в конец. Именно этот шаг делает возможной работу 24/7 без присмотра.
- **Входит за вас** — с учётной записью Aternos aterkeep сам получает cookie сессии и обновляет его по истечении срока. Никаких DevTools и ежемесячного копирования.
- **Анти-простой бот** — клиент Minecraft, который заходит, когда сервер запущен, чтобы его не выключили как пустой
- **Цикл keep-alive** — проверка каждые 90 с, авто-перезапуск сервера (отключается)
- **Веб-панель** — статус в реальном времени, запуск/остановка/перезапуск, переключатель авто-старта
- **Консоль сервера** — живой лог сервера в браузере
- **Редактор настроек** — чтение/изменение `server.properties` из панели
- **Список игроков** — кто онлайн
- **Request inspector** — каждый HTTP-запрос с JSON-ответом (обучающе)
- **14 языков** — интерфейс переключается в шапке
- **Шифрованная сессия** — куки в AES-256-GCM, ключ никогда не покидает ваш ПК

## Требования

- Windows 10/11 (использует встроенный `curl.exe`)
- Rust toolchain (только для сборки)

## Установка

```powershell
cd rust
cargo build --release
# бинарник: target/release/aterkeep.exe
```

## Установка (один раз)

Запустите бинарник и откройте **http://127.0.0.1:4041**. Мастер спросит три
вещи: язык панели, пароль панели и сессию Aternos.

**Пароль панели** защищает панель *и* шифрует сессию. Ключ **никогда не
записывается на диск**: он выводится из пароля при каждом запуске
(PBKDF2-HMAC-SHA256, 600 000 итераций). **Восстановления нет.**

**Два способа задать сессию:**

**1. Учётная запись Aternos (по умолчанию).** Введите имя пользователя и пароль:
aterkeep входит по обычному HTTP и получает cookie сам. Если серверов несколько,
мастер спросит, какой поддерживать. Учётные данные лежат в `config/session.enc`
под тем же шифрованием AES-256-GCM, что и cookie, и отправляются только на
`aternos.org`.

> Не работает при **двухфакторной аутентификации** и если Aternos требует
> **капчу**; о каждом случае сообщается отдельно.

**2. Вставка cookie (запасной путь).** На `aternos.org`: F12 → **Network** → F5,
скопируйте всю строку `cookie:` любого запроса и выполните `window.AJAX_TOKEN` в
**Console**. Такая сессия **сама не обновляется**.

## Запуск

```powershell
.\target\release\aterkeep.exe
```

Откройте **http://127.0.0.1:4041**.

## Вкладки панели

| Вкладка | Функция |
|---|---|
| **Статус** | бейдж состояния, управление, авто-старт, живой лог, инспектор |
| **Консоль** | поток лога сервера (обновление 10 с) |
| **Настройки** | редактирование `server.properties` и сохранение |
| **Игроки** | список игроков онлайн |

**Переключатель авто-старта важен:** выключен = сервер больше никогда не запустится. **Остановить** выключает его автоматически.

## Срок жизни сессии

Aternos выдаёт cookie с `Max-Age=2592000` — **ровно 30 дней**; это измерено по
ответу на вход, а не угадано.

**С учётной записью:** делать нечего. По истечении демон входит заново и
продолжает работу — одна строка в журнале.

**Со вставленными cookie:** панель показывает значок `SESSION` и предупреждение
об истёкшей сессии — а не выключенный сервер — с кнопкой возврата в мастер.

Панель также показывает **возраст сессии**, а после первого истечения — сколько
продержалась предыдущая.

Автозапуск после перезагрузки: **[docs/AUTOSTART.md](docs/AUTOSTART.md)** (задача Windows с DPAPI, systemd, Termux:Boot).

## Безопасность

- Сессия зашифрована (`session.enc`, AES-256-GCM)
- **На диске нет файла ключа** — ключ выводится из пароля (PBKDF2, 600 000 итераций, случайная соль для каждой установки). Скопированная папка `config/` бесполезна без пароля
- **Панель требует входа** — все эндпоинты защищены сессионной cookie `HttpOnly`
- Строки API зашифрованы в бинарнике, расшифровываются в рантайме вашим ключом
- Панель слушает только `127.0.0.1`
