3 · Aternos oturumu

  1. aternos.org'a gir, giriş yap, sunucu panelini aç
  2. F12 → Network → F5 ile sayfayı yenile
  3. Bir aternos.org isteğine tıkla → Headers → Request Headers → cookie: satırının tamamını kopyala
  4. Console sekmesinde şunu çalıştır ve çıktıyı kopyala:
    window.AJAX_TOKEN + "|" + window.generateAjaxToken()
Cookie nasıl kopyalanır? (adım adım)

Önemli: ATERNOS_SESSION çerezi HttpOnly'dir — document.cookie dahil hiçbir JavaScript komutu onu göremez. Bu yüzden yukarıdaki gibi Network sekmesindeki isteğin cookie: başlığından kopyalaman gerekir. Alternatif: Application → Cookies → https://aternos.org.

Server ID gerekmez: yapıştırdığın çerezlerin içindeki ATERNOS_SERVER değerinden sunucun otomatik tespit edilir.

Güvenlik: Bu çerezler Aternos hesabına erişim sağlar. Kimseyle paylaşma, ekran görüntüsü alma. config/ klasörünü de paylaşma — şifreli olsa bile oturum verisi içerir.
