Panel language

Applies to the whole panel — including this wizard.

2

Panel password

Protects the panel and encrypts your Aternos session. The key is never written to disk; it is derived from this password on every start.

There is no recovery. The password is stored nowhere — if you forget it, the encrypted session can never be opened again.
3

Aternos session

aterkeep signs in for you and keeps the session fresh by itself.

Stored inside session.enc, encrypted with your panel password.

Two-factor accounts cannot use this; switch to Paste cookies.

  1. Open aternos.org, sign in, and open your server panel
  2. F12 → Network → F5
  3. Click any aternos.org request → Headers → Request Headers → copy the entire cookie: line
  4. Run this in the Console and copy the output:
    window.AJAX_TOKEN + "|" + window.generateAjaxToken()
How do I copy the cookie?

The ATERNOS_SESSION cookie is HttpOnly: no JavaScript can read it, not even document.cookie.

No server ID needed — it is detected from the ATERNOS_SERVER value inside the cookies you paste.

These cookies grant full access to your Aternos account. Never share them and never screenshot them. Do not share the config/ folder either.
