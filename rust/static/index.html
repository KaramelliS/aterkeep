Aternos oturumu

  1. aternos.org'a gir, giriş yap, sunucu panelini aç
  2. F12 → Network → F5
  3. Bir aternos.org isteği → Headers → Request Headers → cookie: satırının tamamını kopyala
  4. Console'da çalıştır, çıktıyı kopyala:
    window.AJAX_TOKEN + "|" + window.generateAjaxToken()
Cookie nasıl kopyalanır?

ATERNOS_SESSION çerezi HttpOnly'dir; document.cookie dahil hiçbir JavaScript onu göremez. Bu yüzden Network sekmesindeki isteğin cookie: başlığından kopyalanır. Alternatif: Application → Cookies → https://aternos.org

Server ID gerekmez — yapıştırdığın çerezlerdeki ATERNOS_SERVER değerinden otomatik bulunur.

Bu çerezler Aternos hesabına tam erişim sağlar. Kimseyle paylaşma, ekran görüntüsü alma. config/ klasörünü de paylaşma.
