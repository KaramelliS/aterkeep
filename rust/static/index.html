Hesap Kurulumu

Sunucunuza bağlanmak için Aternos oturum çerezleri gerekli. İki yol:

Başlat'a bas → bir Chromium penceresi açılır. O pencerede:

  1. Aternos'a giriş yap (kullanıcı adı + şifre)
  2. Sunucu paneline gir (sunucunu seç)
  3. Geri kalanını otomatik yapar — çerezler + token çekilir, pencere kapanır
  1. aternos.org'a gir, giriş yap, sunucu panelini aç
  2. F12 → Network (Ağ) → F5 ile yenile
  3. Bir aternos.org isteğine tıkla → Headers → Request Headers → cookie: satırının değerini kopyala
  4. Console → window.AJAX_TOKEN + "|" + window.generateAjaxToken() → değeri kopyala
  5. İkisini aşağıya yapıştır → Kur
Cookie nasıl kopyalanır? (adım adım)

Önemli: ATERNOS_SESSION çerezi HttpOnly — hiçbir JavaScript komutu onu göremez. Tek yol yukarıdaki gibi Network'ten kopyalamak, ya da browser ile otomatik modu kullanmak (önerilen).
